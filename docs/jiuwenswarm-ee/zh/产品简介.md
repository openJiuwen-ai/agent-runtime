# JiuwenSwarm 企业版产品简介

> JiuwenSwarm（蜂群）是 openJiuwen 社区的多智能体协作系统：单机上，它是一支会分工的 Agent 团队；集群里，它是全公司共享的智能体基础设施。

## JiuwenSwarm 企业版是什么

JiuwenSwarm 是 openJiuwen 社区 Coordination Engineering（协同工程）技术栈的核心载体，让多个 Agent 像蜂群一样自主分工、动态协作，完成任务后各归其位。

它有两种形态，覆盖从个人开发者到大型企业的完整路径：

- **单机版**：在个人桌面或单台服务器上运行一支 Agent 团队，多智能体协作在本机形成闭环——这是大多数开发者接触 JiuwenSwarm 的起点；
- **企业版**：以企业级分布式集群为底座的资源池化平台，让成百上千支 Agent 团队在共享资源池里同时、安全、有序地运行。

**企业版**核心主张一句话：**规模与成本兼得，治理与安全并举，性能与稳定兼顾。**

## 核心能力

| 能力 | 价值 |
| --- | --- |
| 资源池化与弹性 | Agent 实例全生命周期自动托管，空闲回收、高峰扩容，用更少的资源扛更多的业务 |
| 统一管控 | 组织准入、Agent 编排、配额限制、全链路审计收敛到管理面，全局可控、可追溯、可回滚 |
| 纵深安全 | 多层身份门禁 + 多租户数据硬隔离 + 企业级沙箱，从身份到数据、从工具到执行，每个边界都有防线 |
| 高可用与性能 | 全组件多副本无单点，实测千级并发秒级响应，支持水平扩展至更大规模 |

## 两种形态，按需选择

| | 单机版 | 企业版 |
| --- | --- | --- |
| 部署形态 | 个人桌面 / 单台服务器，本机闭环 | 云原生集群，全组件多副本 |
| 蜂群协作 | Swarm / Team / Flow / Symphony | 同样完整支持 |
| 资源与弹性 | 本机资源，独占使用 | 共享资源池 + 按需分配 + 动态扩缩容 |
| 管控与审计 | 面向单实例 | 组织准入 / 配额 / 配置灰度 / 全链路审计 |
| 安全隔离 | 本地环境边界 | 多层门禁 + SSO 对接 + 多租户硬隔离 + 沙箱 |
| 典型规模 | 单实例 | 千级并发实测，水平扩展 |

**怎么选**：个人使用、原型验证、几人小团队 → 单机版；全公司接入、多部门共享、有合规与审计要求 → 企业版。

## 快速开始

1. **单机版**：访问 openJiuwen 社区仓库获取安装指引（见下方相关资源）；
2. **企业版**：联系 openJiuwen 社区获取部署指南与 POC 支持；
3. **理解设计**：继续阅读《整体架构》，了解分层设计、请求生命周期与关键权衡。
