Agent Runtime 首版本主要支持低码方式的 Agent 发布：与 openJiuwen Studio 联动，输入 Agent IR 文件后即可一键部署并拉起 Agent 服务。

当前版本推荐通过源码方式使用 Runtime，拉取代码后可通过启动脚本一键完成安装与启动。

# 环境要求
* python>=3.11.4
* uv>=0.25.x
* git（用于拉取代码）
* bash（Linux/macOS 系统）或 PowerShell（Windows 系统）


# 一键启动 Runtime 服务

### 1) 获取代码

```shell
git clone https://gitcode.com/openJiuwen/agent-runtime.git
cd agent-runtime
```

### 2) 准备环境配置

```shell
cd agent-runtime/server
cp .env.example .env
```

按需修改 `.env` 中的配置项，重点包括：
* `DB_TYPE`：支持 `mysql` 和 `sqlite`
* 其他运行时相关参数（如ip地址、端口号等）

### 3) 执行启动脚本：

* Linux/MacOS：
  ```shell
  bash scripts/run-server.sh
  ```

* Windows（PowerShell）：
  ```powershell
  .\scripts\run-server.ps1
  ```

默认启动后可通过 `8186` 端口访问 Runtime 服务。


# 发布智能体
Runtime 支持两种智能体发布方式：低码发布（通过 Studio 一键发布）和高码发布（待开放）。


## 通过studio发布低码智能体

在 Runtime 服务启动后，需要在 openJiuwen Studio 后端的 `.env` 中配置好 Runtime 的地址和端口，完成对接后即可在 Studio 中一键发布 Agent。

### 在studio中配置runtime服务连接
在agent-studio根目录，从`.env.example`复制`.env`文件，打开`.env`文件，修改runtime服务的配置：


  ```shell
   # Runtime 服务配置（样例）
   RUNTIME_HOST=localhost
   RUNTIME_PORT=8186
   ```

### 发布智能体

#### 操作步骤

1. 进入智能体编辑页面，配置好智能体的信息并调试成功，点击 `发布` 按钮。
2. 页面将打开发布弹窗，可选择草稿版本或之前已经提交的版本发布。如果选择草稿版本，会弹出版本提交界面，把当前草稿提交为新版本后发布。

![alt text](images/runtime-publish.png)

3. 发布完成后，会展示“发布成功卡片”，可点击`发布管理`按钮进入发布管理页面查看发布的智能体的详情。

![alt text](images/runtime-publish-success.png)

4. 发布后，在智能体编辑页面右上角有`发布管理`入口按钮。鼠标悬浮在`发布`按钮上，也能看到发布信息。

![alt text](images/runtime-publish-info.png)

### 对话体验

进入发布管理页面后，在对话体验页签下，可以进行对话体验测试智能体的效果。

![alt text](images/runtime-management-chat.png)


### 查看API调用示例

api调用页签展示调用运行态智能体的API参数（包括请求方式、url、body、返回结构等）。在请求配置里输入参数，会把你输入的参数自动放入右侧curl/python/javascript示例代码中，便于你直接复制样例代码运行。

![alt text](images/runtime-management-api.png)


### 下架智能体

当你不需要该运行态的智能体时，可以在发布管理页标题栏右侧点击 `下架` 按钮， 页面会弹出确认框，点击确认后，系统将移除该智能体的运行态部署。下架成功后，会提示成功并跳转回智能体列表页。


![alt text](images/runtime-management-offline.png)
