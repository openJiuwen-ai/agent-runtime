# 专家包配置

一行专家包模板是一套 Hub 包组合，里面可以同时有专家和专家团。Agent 模板选择这一行。把这只 Agent 发布到集群后，谁能用这只 Agent，谁就能用这套包。

隐藏的四个 Hub 包不会出现在清单里，也不能写进组合。

## 使用流程

1. 已登录管理员从侧栏 **Agent资源 → 专家包** 新建一套组合
2. 在 **Agent模板** 的模板引用里选择这一套
3. 把这只 Agent 发布到某个集群
4. 已准入且命中这只 Agent 授权的普通用户打开聊天页，安装并选用这套包里的专家或专家团

## 管理端配置

### 入口与列表

已登录管理员打开管理端。侧栏入口是 **Agent资源 → 专家包**。

列表有模板名称、模板描述、**包含**、启用、被引用、更新时间。**包含**按这一行里的包计数，例如「专家 3 个 · 专家团 3 个」。搜索按名称、描述和 Hub 标识。页头可以刷新、导入，每一行可以导出。

![专家包列表](assets/image-20261103201427357.png)

### 新建一套专家包

点击 **新建专家包**。页面列出 Hub 上的专家和专家团，分两栏。

| 字段 | 说明 |
| ---- | ---- |
| **模板名称** | 必填。这套组合的名字 |
| **模板描述** | 可选 |
| **Hub 包** | 必填。专家、专家团分栏，可以同时勾选多个。保存后全部写入这一行 |

Hub 暂时打不开时，新建没有可选项。已经保存的行仍在列表里。

![新建专家包](assets/image-20261103201528843.png)

### 编辑、禁用与删除

- **编辑**：可以改名称和描述，也可以增减包。Hub 打不开时，已选中的包仍可查看和取消勾选
- **禁用**：列表开关关闭后，Agent 模板的可选项里不再出现这一行。已经发布到集群的这一行停用后，使用这只 Agent 的人不再能安装和使用这套包
- **删除**：仍被 Agent 模板引用时不能删除。先在那些 Agent 上取消选择，再回到专家包页删除
- **被引用**：数字是引用这一行的 Agent 模板数。点击后进入 Agent 模板页

### 导入与导出

- **导出**：在某一行点击导出，下载这一套专家包模板
- **导入**：页头 **导入** 选择此前导出的文件，写入这一行组合。在 Agent 模板里选中后，随这只 Agent 下发

### 在 Agent 模板里选择

已登录管理员打开 **Agent模板**，新建或编辑一只 Agent。模板引用里有一个 **专家包** 下拉框，列出已启用的专家包模板。选中这一套后保存。该槽允许一条。

槽旁边的引导回到专家包页。

![Agent 模板的专家包槽](assets/image-20261103201615060.png)

## 随这只 Agent 发布

把这只 Agent 发布到某个集群时，被选中的专家包模板跟着发到那台集群。能用这只 Agent 的人，就能用这一行里的专家和专家团。

再次保存已经发布过的模板时，变更会发到那些集群。加减包改这一行。

## 在聊天页使用

已准入且命中这只 Agent 授权的普通用户打开聊天页。左侧点 **专家**，进入「专家管理」。广场只列出这只 Agent 绑上的那一套。

### 安装专家

1. 打开 **专家广场**
2. 在卡片上点 **安装**，或打开详情后再点 **安装**
3. 安装完成后，切到 **我的专家 → 专家**，能看到这一份

![专家广场](assets/image-20261103202504156.png)

![我的专家里已安装的专家](assets/image-20261103202549650.png)

### 安装专家团

1. 打开 **专家团广场**
2. 在卡片上点 **安装**，或打开详情后再点 **安装**
3. 安装完成后，切到 **我的专家 → 专家团**，能看到这一份

![专家团广场](assets/image-20261103202606593.png)

![我的专家里已安装的专家团](assets/image-20261103202648053.png)

对话处在单 Agent 模式时，选中已安装的专家再发送。

![单 Agent 模式选中已安装的专家](assets/image-20261103202807717.png)

选用专家团时，先把对话切到集群模式，在这条团队会话第一次发出消息之前选好，再发送。

![集群模式选好专家团](assets/image-20261103202909429.png)

## 去掉不再使用的包

管理员在这套专家包模板里取消对应的包并保存。已经发布到集群的模板会重新下发。用户刷新广场和输入框里的选择列表后，这个包不再出现。

不再被任何 Agent 模板引用的专家包模板，可以在专家包页删除。
