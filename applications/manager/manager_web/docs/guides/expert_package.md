# 专家包配置

## 先建成一套专家包

已登录管理员打开管理端。从侧栏「Agent资源」进入「专家包」。新建时填写这套组合的名称，页面向 Hub 平台要专家和专家团清单，分栏列出，可以同时勾选多个。保存后这些包写进同一行专家包模板。

编辑时可以改名称，也可以增减包。Hub 暂时打不开时，已经保存的模板仍在列表里，已选中的包仍显示，只是不能新增。新建没有可选项。

隐藏的四个 Hub 包不会出现在清单里，也不能写进组合。

## 在 Agent 模板里选择

从侧栏「Agent资源」进入「Agent模板」，新建或编辑一只 Agent。模板引用里有一个「专家包」单选槽，选项是已经建成的专家包模板。选中后写入的是这一行的 template_id。

槽旁边的引导回到专家包模板页。

## 随这只 Agent 发布

把这只 Agent 发布到某个集群时，被选中的专家包模板跟着下发到那台集群的 Gateway。Gateway 把这一行里的包展开后，谁能用这只 Agent，谁就能用这套专家和专家团。

已经发布过的模板再次保存时，现有模板更新会把它重新推到那些 Gateway。加减包只改这一行。

## 在聊天页使用

已准入且命中这只 Agent 授权的普通用户打开管理端的 `/chat/`。在专家广场或专家团广场打开详情并安装。

对话处在单 Agent 模式时，选中已安装的专家再发送。选用专家团时，先把对话切到集群模式，在这条团队会话第一次发出消息之前选好，再发送。

## 去掉不再使用的包

管理员在这套专家包模板里取消对应的包并保存。已经发布到集群的模板会重新下发。用户刷新广场和输入框里的选择列表后，这个包不再出现。

不再被任何 Agent 模板引用的专家包模板，可以在专家包页删除。

以前写在「专家」「专家团」槽里的模板号，以及一行只存一个 Hub 包的旧数据，发布后都解析不到，按没有这套包处理。需要继续使用时，按新结构建成一套组合，再在 Agent 模板上重新选择。
