# 专家包配置

专家包模板将多个 Hub 专家和专家团组合成一套可复用能力。在 Agent 模板中绑定后，专家包会随 Agent 发布到集群，使用范围由该 Agent 的授权决定。

## 使用流程

1. 已登录管理员从侧栏 **资源中心 → 专家与专家包** 新建一套组合
2. 在 **工作台 → Agent模板管理** 新建或编辑模板，展开 **可选能力配置**，选择该专家包模板并保存
3. 在 **集群管理 → Agent绑定** 将该 Agent 模板绑定到目标集群
4. 已准入且具备该 Agent 使用权限的普通用户打开聊天页，安装并选用这套包里的专家或专家团

## 管理端配置

### 入口与列表

已登录管理员打开管理端。侧栏入口是 **资源中心 → 专家与专家包**。

列表有模板名称、模板描述、**包含**、启用、被引用、更新时间。**包含**按该模板里的包计数，例如「专家 3 个 · 专家团 3 个」。搜索按名称、描述和 Hub 标识。页头可以刷新、导入，每一行可以导出。

![专家包列表](assets/image-20261103201427357.png)

### 新建一套专家包

点击 **新建专家包**。页面列出 Hub 上的专家和专家团，分两栏。

| 字段 | 说明 |
| ---- | ---- |
| **模板名称** | 必填。这套组合的名字 |
| **模板描述** | 可选 |
| **Hub 包** | 必填。专家、专家团分栏，可以同时勾选多个。保存后全部写入该模板 |

Hub 暂时打不开时，新建没有可选项。已经保存的行仍在列表里。

![新建专家包](assets/image-20261103201528843.png)

### 编辑、禁用与删除

- **编辑**：可以改名称和描述，也可以增减包。Hub 打不开时，已选中的包仍可查看和取消勾选
- **禁用**：列表开关关闭后，Agent 模板的可选项里不再出现该模板。已经发布到集群的该模板停用后，使用该 Agent 的人不再能安装和使用这套包
- **删除**：仍被 Agent 模板引用时不能删除。先在那些 Agent 上取消选择，再回到专家包页删除
- **被引用**：数字是引用该模板的 Agent 模板数。点击后进入 Agent 模板页

### 导入与导出

- **导出**：在某一行点击导出，下载这一套专家包模板
- **导入**：页头 **导入** 选择此前导出的文件，写入该模板组合。在 Agent 模板里选中后，随该 Agent 下发

### 在 Agent 模板里选择

已登录管理员打开 **工作台 → Agent模板管理**，新建或编辑 Agent 模板。在 **可选能力配置** 中找到 **专家与专家包** 卡片，选择已启用的专家包模板并保存。每个 Agent 模板可绑定一套专家包。

卡片右侧的页面跳转按钮可以打开资源中心的 **专家与专家包** 页面。绑定随 Agent 模板保存到后端，并参与模板导入导出和集群发布。

![Agent 模板的专家包槽](assets/image-20261103201615060.png)

## 随 Agent 发布

在集群的 **Agent绑定** 页面绑定 Agent 模板后，所选专家包模板会一起下发到该集群。已准入且具备该 Agent 使用权限的用户，可以使用其中的专家和专家团。

编辑已发布的专家包模板并保存后，变更会重新下发到引用它的集群。需要增减专家或专家团时，在这套模板中统一维护。

## 在聊天页使用

已准入且具备该 Agent 使用权限的普通用户打开聊天页。左侧点 **专家**，进入「专家管理」。广场只列出该 Agent 绑上的那一套。

### 安装专家

1. 打开 **专家广场**
2. 在卡片上点 **安装**，或打开详情后再点 **安装**
3. 安装完成后，切到 **我的专家 → 专家**，能看到这一份

![专家广场](assets/image-20261103202504156.png)

![我的专家里已安装的专家](assets/image-20261103202549650.png)

### 安装专家团

1. 打开 **专家团广场**
2. 在卡片上点 **安装**，或打开详情后再点 **安装**
3. 安装完成后，切到 **我的专家 → 专家团**，能看到这一份

![专家团广场](assets/image-20261103202606593.png)

![我的专家里已安装的专家团](assets/image-20261103202648053.png)

对话处在单 Agent 模式时，选中已安装的专家再发送。

![单 Agent 模式选中已安装的专家](assets/image-20261103202807717.png)

选用专家团时，先把对话切到集群模式，在这条团队会话第一次发出消息之前选好，再发送。

![集群模式选好专家团](assets/image-20261103202909429.png)

## 去掉不再使用的包

管理员在这套专家包模板里取消对应的包并保存。已经发布到集群的模板会重新下发。用户刷新广场和输入框里的选择列表后，这个包不再出现。

不再被任何 Agent 模板引用的专家包模板，可以在专家包页删除。
