# 专家包配置

## 进入专家包

已登录管理员打开管理端。从侧栏「资源中心」进入「专家与专家包」，默认在「资源目录」浏览专家和专家包（专家团）。当前需要选择一个集群连接以读取 Hub 目录；此目录来源不决定 Agent 模板绑定的集群。

## 在 Agent 模板中配置（前端预览）

进入「工作台 → Agent模板管理」，在新建或编辑模板时展开「专家与专家包 · 可选」，选择所需能力。已有模板可单独保存绑定预览，模板详情和集群 Agent 绑定弹窗会显示同一份预览。后端接口尚未实现，选择仅保存在当前浏览器，不下发、不改变真实授权，也不包含在模板导入导出中。

离线查看界面时可以主动切换到「界面演示（仅预览）」，演示资源有单独标记。真实目录不可用时不会自动伪造包列表。

## 使用现有集群发布功能

需要配置当前已有的专家包授权时，切换「集群发布（现有功能）」，选择目标集群，在「专家」或「专家团」中勾选要发布的包。该功能继续使用现有集群白名单接口，与尚未接入后端的模板绑定预览分开保存。

![专家包列表](assets/image-20261102211636799.png)

## 授权并保存

一次可以勾选多个包，并给它们设同一份授权范围。范围留空时，这个集群里已准入的用户都能用；也可以只允许指定用户或组织，或把某些用户、组织排除在外。保存后立刻发到该集群。

![添加专家包](assets/image-20261102211721303.png)

## 在聊天页使用

已准入且授权命中的普通用户打开管理端的 `/chat/`。在专家广场或专家团广场打开详情并安装。

![专家广场](assets/image-20261103094146109.png)

对话处在单 Agent 模式时，选中已安装的专家再发送。选用专家团时，先把对话切到集群模式，在这条团队会话第一次发出消息之前选好，再发送。

![选用专家](assets/image-20261103094159424.png)

## 移除已发布的包

管理员从该集群移除这个包并保存。用户刷新广场和输入框里的选择列表后，这个包不再出现。
