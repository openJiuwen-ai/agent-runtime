# 专家包配置

## 进入专家包

已登录管理员打开管理端。从侧栏「集群管理」进入某个集群，再打开「集群配置」下的「专家包」。候选项来自这个集群自己的 Hub，分成「专家」和「专家团」。

![专家包列表](assets/image-20261030185800001.png)

## 授权并保存

一次可以勾选多个包，并给它们设同一份授权范围。范围留空时，这个集群里已准入的用户都能用；也可以只允许指定用户或组织，或把某些用户、组织排除在外。保存后，这一集群之前的发布被整份替换，并立刻发到该集群。

![添加专家包](assets/image-20261030185800002.png)

## 在聊天页使用

已准入且授权命中的普通用户打开管理端的 `/chat/`。聊天页里打开专家广场或专家团广场，能看到这些包，打开详情并安装。

![专家广场](assets/image-20261030185500003.png)

对话处在单 Agent 模式。选中该专家后发送一条消息。

![选用专家](assets/image-20261030185600004.png)

## 移除已发布的包

管理员从该集群移除这个包并保存后，用户刷新广场和输入框里的选择列表，这个包不再出现。已经打开的会话仍可看历史。再发下一条时，按当时的名单校验。

## 尚未发布或清空

还没有发布，或把该集群的发布清空后，来自 Hub、官方内置和随资源下发的专家、专家团都不会出现在广场里，也不能安装。
