# 专家包配置

## 进入专家包

已登录管理员打开管理端。从侧栏「Agent资源」进入「专家包」，再用页头的集群下拉选中目标集群。在「专家」或「专家团」里勾选要发布的包。

![专家包列表](assets/image-20261030185800001.png)

## 授权并保存

一次可以勾选多个包，并给它们设同一份授权范围。范围留空时，这个集群里已准入的用户都能用；也可以只允许指定用户或组织，或把某些用户、组织排除在外。保存后立刻发到该集群。

![添加专家包](assets/image-20261030185800002.png)

## 在聊天页使用

已准入且授权命中的普通用户打开管理端的 `/chat/`。在专家广场或专家团广场打开详情并安装。

![专家广场](assets/image-20261030185500003.png)

对话处在单 Agent 模式时，选中已安装的专家再发送。选用专家团时，先把对话切到集群模式，在这条团队会话第一次发出消息之前选好，再发送。

![选用专家](assets/image-20261030185600004.png)

## 移除已发布的包

管理员从该集群移除这个包并保存。用户刷新广场和输入框里的选择列表后，这个包不再出现。
