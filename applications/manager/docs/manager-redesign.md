# Manager 工作台改版

## 目标与边界

以管理员的任务组织页面：定义 Agent、准备资源、接入运行环境、授权、检查运行状态。保留现有 API 和历史深链接，不复制用户端对话、技能执行、记忆等功能。生产环境配置不变，本地账号仅用于隔离开发数据库。

## 信息架构

- 总览：服务连接健康、异常实例、首次配置步骤、快捷操作。
- Agent 管理：可复用定义、能力摘要、发布配置入口。Agent 定义和实例绑定分别展示。
- 资源中心：生成模型、向量模型、Skill、MCP、A2A、高级扩展。
- 运行环境：服务实例、运行规格、容器模板。
- 安全与访问：用户、组织、角色、工具安全策略；实例准入保留在实例上下文中。
- 运营：仅在权限与功能开关允许时提供审批入口。成本、Token 和业务审计占位页从常规导航移除，兼容旧链接。

## 实施顺序

1. 开发账号与基础布局：独立账号初始化，重组导航、统一视觉与布局。
2. 总览：真实加载/错误/空态，分页聚合实例，三组件连接健康；不将探活等同于 Agent 执行成功。
3. Agent：能力引用摘要、详情、实例绑定向导。授权采用现有表达式，不创建隐式准入或自动修改运行时策略。
4. 环境与通用页面：上下文导航、可用功能筛选、表格固定操作列、复杂表单分组，保留全部字段。
5. 验证：构建、现有测试、核心逻辑测试、浏览器检查、本地认证与 API 联调。

## 状态契约

- 模板启用只表示可用于配置，不代表已部署。
- 绑定 API 成功只说明配置已保存；无运行时确认时不得显示“已生效”。
- 绑定前可检查是否已有运行规格，不能仅凭存在一条规格证明某个用户会命中。
- 有效权限模拟、版本发布/回滚、成本统计需要后端权威计算，不能由前端猜测；本轮保留明确的检查入口与边界，不伪造能力。
- 不导入线上实例或密钥，不用假业务数据冒充运行结果。

## 视觉规范

浅色中性背景、蓝色主操作、低对比边框；暗色保持同等语义。侧栏分组稳定，页面主标题/说明/主操作一致。列表名称可读、ID 为次级信息；末列操作固定。复杂配置分为基础与高级，状态文字不依赖颜色。

## 验收场景

空库管理员能识别配置顺序；读取失败不会显示为零或“健康”；超过一页的数据按完整集合统计；Agent 绑定流程保留失败输入且显示真实保存结果；受限账号不能通过新增路由绕过旧权限；中英切换与暗色可用；窄桌面布局无页面整体横向溢出。

## 第一轮实现（2026-10-30）

已实现：任务域导航、真实 API 总览、多页实例统计、三组件健康判定、Agent 卡片目录、三步实例绑定页面、隐藏常规导航中的成本/业务审计/Token 占位入口、运行规格高级部署折叠、固定表格末列、移除全局 AI 免责声明。旧模板目录与深链接保留。开发账号固定为 admin/admin、user/user，仅修改隔离本地数据库。

验证：前端构建通过；20 项现有/新增测试通过。浏览器确认总览、Agent 空态和新建表单；默认模型缺失正确阻止保存。账号登录和普通用户管理 API 403 已验证。

尚未完成验收：真实模型/实例齐备后的绑定成功与失败流程、完整暗色/窄屏矩阵。尚待后续设计实现：Agent 详情中的资源名称解析与绑定列表、可保存草稿的独立复杂编辑页、有效权限解释后端、版本化发布/回滚、生效状态追踪。当前绑定 API 只表达保存成功。

## 第二轮实现（2026-10-30）

新增 Agent 详情：按名称展示模型/技能/MCP/护栏/A2A 策略引用，单条读取失败独立显示；跨实例、跨页查询绑定，保留实例失败状态，展示有效期与授权条件。卡片入口连接详情页，旧目录继续支持完整管理操作。绑定向导新增同模板绑定数量和启用运行规格检查，不把存在规格当作匹配成功。共享异步 Hook 通过请求序号防止旧请求覆盖新结果。

验证：22 项测试通过，包含引用部分失败、策略名称映射和跨页绑定；构建通过。浏览器确认本地 Agent 入口。由于当前本地库为空，详情页有数据布局与完整保存流程仍需开发样例数据验证；不使用线上业务数据填充。

## 第三轮实现（2026-10-30）

绑定向导增加当前标签页草稿，按账号与 Agent 隔离，离开页面返回可恢复；保存后清除，主动清除采用页面内二次确认。存储失败提示用户，损坏草稿回退为空表单；恢复时检查实例是否仍可用。绑定详情区分过期、长期有效和异常日期，不用启用开关替代有效期。

新增显式执行的本地演示脚本，停用模型使用 `.invalid` 地址，不调用外部服务。浏览器已验证有数据详情的名称解析、停用状态、无实例时禁用下一步、离开返回恢复名称和确认清除草稿。前端 25 项测试通过、生产构建通过。现有测试中的 Vite WebSocket 端口警告及构建的大包警告仍在。真实实例绑定保存、运行时生效和完整响应式/语言/主题矩阵尚未验证。

## 持续引导与摘要视图首版

首页四步启动跨路由配置引导，展示模型必需项、技能/MCP 可选项、安全策略及下一阶段入口，支持收起和退出。当前进度仅保留在应用内存中，不做自动完成判定，不选择或预填资源；刷新恢复、按 Agent 保存任务和保存后推荐动作仍待实现。

Agent 列表新增原生 dialog 侧边摘要，保留列表上下文，并提供完整详情和编辑入口。实例简洁视图改为横向摘要行，集中展示三个组件状态、配置告警和检查入口；原详细表格继续提供排序、筛选、导出和删除操作。

验证：构建和 25 项测试通过；浏览器走通首页到模型、MCP、Agent 的连续引导，验证摘要打开关闭。有数据实例摘要尚未进行浏览器验证。所有资源列表的统一改造尚未完成。

## 快速开局对齐与服务器配置发现

对照 `manager_web/docs/getting-started.md` 校正配置引导：成员与组织现在属于使用范围阶段，并明确组织绑定成员、集群准入、集群内 Agent/运行时授权，最后进入用户面对话；运行环境拆分为服务实例、容器模板和运行规格。

运行时模板页新增“从服务器发现”入口。Manager 服务端仅从显式的 `AGENTSERVER_JSON_PATH` 或 `MANAGER_DEPLOY_TOOL_DIR/conf/agentserver.json` 读取部署脚本生成的配置，浏览器不直接访问服务器文件；未配置或文件尚未生成时保留本地 JSON 上传并提示原因。该能力尚未在真实部署工具目录做端到端验证。
