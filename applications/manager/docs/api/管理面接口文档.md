# 管理面接口文档


## 1. 总览


| 项 | 说明 |
| --- | --- |
| 服务 | `manager_server`（FastAPI） |
| 默认端口 | `MANAGER_REST_PORT`，缺省 **8765** |
| Base URL | `http://{host}:8765`（经 manager-web 反代时一般为同源 `/api/...`） |
| 路径前缀 | `/api`；业务接口在 `/api/v1` |
| 响应信封 | `{ "code": 200, "message": "success", "data": ... }` |
| 鉴权 | 除探活等少数公开接口外，需 `Authorization: Bearer <JWT>`；多数管理写接口还要求平台管理员 |


**与 Gateway Config Receiver 对照**


| 维度 | Manager REST | Gateway Config Receiver |
| --- | --- | --- |
| 调用方 | 管理控制台 / 运维脚本 | Manager `gateway_request` |
| 配置权威 | 是（读以 Manager DB 为准，写先推 Gateway 再落库） | 否（下发副本） |
| 身份 | JWT + 本地授权表 | 内网 / TLS / Link 绑定（见实例 link-binding） |
| 模板 `template_id` | 创建时由服务端生成 UUID（容器模板除外，客户端传 `container_id`） | 推送时 Body 必带已有 `template_id` |

## 2. 公共约定



### 2.1 鉴权

```http
Authorization: Bearer <RS256 JWT>
```

- JWT 由 Identity 服务签发；Manager 用 `IDENTITY_PUBLIC_KEY_URL` 拉取公钥验签。
- `/api/v1/*` 默认依赖登录用户（`get_current_user`）。
- 挂在 admin 子树的接口额外要求平台管理员（`require_admin`）：模板、实例、实例资源、应用配置、导入导出、实例准入等。
- 配额接口使用权限点：`quota:read` / `quota:write`（不强制 admin 角色，但需对应权限）。
- 授权接口使用：`iam:role:read` / `iam:role:write`；审批接口使用：`approval:read` / `approval:act`。


### 2.2 统一响应

```json
{
  "code": 200,
  "message": "success",
  "data": null
}
```


| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `code` | int | 业务码，成功为 `200` |
| `message` | string | 文案，成功多为 `success` |
| `data` | object \| array \| null | 业务结果 |


| HTTP | 含义 |
| --- | --- |
| 200 | 成功 |
| 400 | 业务校验失败（`detail`） |
| 401 | 未登录 / JWT 无效 |
| 403 | 无管理员或无权限；配额功能关闭时为 `WORKSPACE_QUOTA_FEATURE_DISABLED` |
| 404 | 资源不存在 |
| 409 | 冲突（如 link-binding、导入 confirmation_token 不一致） |
| 502 | 部分场景落库成功但 Gateway 同步未完成（如 A2A discovery settings） |
| 503 | Identity 公钥不可用 / Identity 服务不可用 |


### 2.3 列表分页约定

多数列表接口 Query：


| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `page` | int | 默认 `1`，`>=1` |
| `page_size` | int | 默认 `20`，上限多为 `200`（用量列表上限 `100`） |
| `enabled` | bool | 可选筛选 |
| `search` | string | 可选模糊搜索 |
| `sort_by` / `sort_order` | string | 可选；`sort_order` 为 `asc` / `desc` |


返回 `data` 常见形态：

```json
{
  "items": [ ... ],
  "total": 42,
  "page": 1,
  "page_size": 20
}
```


### 2.4 调用形态

```text
GET/POST/PUT/PATCH/DELETE  {base}/api/v1/...
Authorization: Bearer ...
Content-Type: application/json   # 有 Body 时
```


### 2.5 模板类通用约定

- **鉴权**：需平台管理员。
- **业务 ID**：除容器模板（客户端传 `container_id`，API `template_id` 与其同值）外，创建时 **不传** `template_id` / `policy_id`，由服务端生成 UUID。
- **路径参数**：`template_id` / `policy_id` 长度 1–100。
- **CRUD 形态**：


| 操作 | 方法 | 路径模式 |
| --- | --- | --- |
| 创建 | `POST` | `/api/v1/{collection}` |
| 列表 | `GET` | `/api/v1/{collection}` |
| 详情 | `GET` | `/api/v1/{collection}/{template_id}` |
| 更新 | `PATCH` | `/api/v1/{collection}/{template_id}` |
| 删除 | `DELETE` | `/api/v1/{collection}/{template_id}` |

## 4. 实例（`instance_info` / `/api/v1/instances`）

需管理员。实例标识为 `jiuwenclaw_id`（创建时服务端生成）。



### 4.0 表结构（`instance_info`）


| 字段名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `jiuwenclaw_id` | VARCHAR(64) PK | 是 | 对外实例 ID；创建时服务端生成。 |
| `jiuwenclaw_name` | VARCHAR(128) | 是 | 展示名称。 |
| `description` | VARCHAR(4096) | 否 | 描述。 |
| `namespace` | VARCHAR(64) DEFAULT `default` | 是 | 共用命名空间。 |
| `gateway_host` | VARCHAR(512) | 是 | Gateway 配置下发基址（无尾 `/`）；全局唯一。 |
| `gateway_status` | VARCHAR(32) DEFAULT `pending` | 是 | Gateway 探活状态；不可由 PATCH 改写。 |
| `gateway_last_alive` | DATETIME | 否 | Gateway 上次存活时间。 |
| `runtime_host` | VARCHAR(512) | 是 | Runtime `config_sync` 基址；全局唯一。 |
| `runtime_status` | VARCHAR(32) DEFAULT `pending` | 是 | Runtime 探活状态。 |
| `runtime_last_alive` | DATETIME | 否 | Runtime 上次存活时间。 |
| `user_web_host` | VARCHAR(512) DEFAULT `""` | 是 | 用户面 Web 入口；全局唯一。 |
| `user_web_status` | VARCHAR(32) DEFAULT `pending` | 是 | User Web 探活状态。 |
| `user_web_last_alive` | DATETIME | 否 | User Web 上次存活时间。 |
| `space_id` | VARCHAR(64) DEFAULT `default` | 是 | 空间 ID。 |
| `data` | JSON | 否 | 扩展；含 `gateway_web_http_host` / `gateway_web_ws_host` 等。 |
| `created_at` | DATETIME | 是 | 创建时间。 |
| `created_by` | VARCHAR(64) | 是 | 创建人。 |
| `updated_at` | DATETIME | 是 | 更新时间。 |
| `updated_by` | VARCHAR(64) | 否 | 更新人。 |


**关联表**：`instance_link_binding`（link-binding）、`instance_enc_pubkey`（加密公钥，内部）。

**Manager 触发**：创建前三端探活；Gateway 上线时全量配置同步；删除触发 Gateway lifecycle purge。



### 4.1 创建实例

- **接口名称**：创建实例
- **请求方法**：`POST`
- **请求路径**：`/api/v1/instances/`
- **请求参数**（Body）：


| 字段名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `jiuwenclaw_name` | string | 是 | 展示名称，1–128 |
| `gateway_host` | string | 是 | Gateway 基址，1–512，去尾 `/` |
| `runtime_host` | string | 是 | Runtime 基址 |
| `user_web_host` | string | 是 | 用户面 Web 入口 |
| `gateway_web_http_host` | string | 是 | 写入 `data.gateway_web_http_host` |
| `gateway_web_ws_host` | string | 否 | 写入 `data.gateway_web_ws_host` |
| `description` | string | 否 | ≤4096 |
| `namespace` | string | 否 | 默认 `default` |
| `space_id` | string | 否 | 默认 `default` |
| `created_by` | string | 否 | 默认 `system` |
| `data` | object | 否 | 扩展 |


- **返回参数**：`data` 为实例摘要（含 `jiuwenclaw_id`、各 host/status 等）

## 8. 预置 Skill 模板（`skill_prebuilt_template` / `skill-prebuilt-templates`）

需管理员。创建时服务端生成 `template_id`。

企业预置技能安装为**双模式**（按字段推断，不另传 `mode`）：


| 模式 | 定位 | 说明 |
| --- | --- | --- |
| `provider`（推荐） | 齐 `source_id` + `skill_id` + `version_id` | AgentServer 走 SPI 安装；摘要以 Provider 为准，**不读**模板 `data.sha256`。若同时带 `package_url`，URL **不作**安装入口。 |
| `url`（兼容） | 合法 `package_url`（且走不成 provider） | AgentServer `install_skill_sync(package_url, checksum=data.sha256?)`。可选 `data.sha256`（64 位小写 hex）。 |


Gateway **只存期望态**；写接口成功只表示 Manager/Gateway 模板已保存，真正安装在 AgentServer reconcile。须先于引用它的 Agent 模板推送。



### 8.0 表结构（`skill_prebuilt_template`）


| 字段名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `id` | INTEGER 自增 PK | 是 | 数据库主键；插入时可省略。 |
| `template_id` | VARCHAR(100) UNIQUE | 是 | 对外稳定标识；策略 / Agent `template_ref.skill_prebuilt` 引用本字段。 |
| `template_name` | VARCHAR(128) | 是 | 模板名称。 |
| `description` | VARCHAR(512) | 否 | 用途说明。 |
| `skill_id` | VARCHAR(512) | 是 | 远端/本地定位 ID；两种模式均使用。 |
| `package_url` | VARCHAR(2048) | 条件 | **仅 url 路径**：合法 `http(s)://` 且含主机。 |
| `source_id` | VARCHAR(64) | 条件 | **仅 provider 路径**：已绑定来源 ID。 |
| `version_id` | VARCHAR(128) | 条件 | **仅 provider 路径**：精确制品版本 ID。 |
| `enabled` | BOOLEAN DEFAULT true | 是 | `false` 时不下发到租户预置清单。 |
| `data` | JSON | 否 | 扩展袋。url 路径可用 `data.sha256`；**禁止**在 `data` 内放 `source_id` / `skill_id` / `version_id` / `package_url`。 |
| `created_at` | DATETIME | 是 | 创建时间。 |

## 9. 安全护栏模板（`permissions_template` / `permissions-templates`）

需管理员。创建时服务端生成 `template_id`。

判定只在 **AgentServer**。Gateway / Manager 只存期望态：写接口成功表示模板已落库（及推送），不代表节点已按该策略拦截。

未绑定、模板行 `enabled=false`、或 `body` 无效时，运行时回落 Gateway 本地 `config.yaml::permissions`。

`template_ref.permissions` 为**单值槽位**：绑了多条时，AgentServer 只取第一个**启用**模板的 `body`。



### 9.0 表结构（`permissions_template`）


| 字段名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `id` | INTEGER 自增 PK | 是 | 数据库主键。 |
| `template_id` | VARCHAR(100) UNIQUE | 是 | 对外稳定标识；策略 / Agent `template_ref.permissions` 引用本字段。 |
| `template_name` | VARCHAR(128) | 是 | 模板名称。 |
| `description` | VARCHAR(512) | 否 | 说明，不参与判定。 |
| `enabled` | BOOLEAN DEFAULT true | 是 | 模板行开关；`false` 时不下发，等价未引用。 |
| `body` | JSON | 是 | 完整权限策略，结构与 `config.yaml::permissions` 一致；见下表。 |
| `data` | JSON | 否 | 扩展袋，运行时不参与判定。 |
| `created_at` | DATETIME | 是 | 创建时间。 |
| `updated_at` | DATETIME | 是 | 更新时间。 |


两个开关不要混：行上 `enabled` 控制是否下发；`body.enabled` 是权限引擎总开关（`false` 时工具调用基本放行，内置高危规则仍可能 DENY）。

`body` **字段**（Gateway **不**校验内部语义，只要求是 JSON object；无效 body 运行时回落 yaml）：


| 字段名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `enabled` | bool | 否 | 权限引擎总开关。Manager 新建多为 `true`。 |
| `permission_mode` | string | 否 | `normal`（默认）或 `strict`；把 `rules[].severity` 映射为 allow / ask / deny。 |
| `defaults` | object | 否 | 未列明工具的默认动作；UI 通常只编 `defaults["*"]`（`allow` / `ask` / `deny`）。**勿用 `allow` 作生产默认**（等同关闭护栏）。 |
| `tools` | object | 否 | 键为工具名，值为 `allow` / `ask` / `deny`。`deny` 立即拒绝，不再看 rules。 |
| `rules` | array | 否 | 参数级规则，见 **rule 对象**。 |
| `file_guard` | object | 否 | 路径防护，见 **file_guard 对象**。 |


`rule` **对象**：


| 字段名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `id` | string | 否 | 规则 ID。 |
| `tools` | string[] | 是 | 适用工具；须同一类（shell / path），空或跨类则运行时跳过该条。 |
| `pattern` | string | 是 | 命令模式。通配如 `ls *`；`re:` 开头为正则。 |
| `severity` | string | 否 | `LOW` / `MEDIUM` / `HIGH` / `CRITICAL`，经 `permission_mode` 映射。 |
| `action` | string | 否 | 显式 `allow` / `ask` / `deny`；有则优先于 severity 映射。 |
| `description` | string | 否 | 说明。 |


`file_guard` **对象**：


| 字段名 | 类型 | 说明 |
| --- | --- | --- |
| `enabled` | bool | `false` 时整层路径防护关，不影响 tools/rules。 |
| `defaults` | object | 未命中 workspace / paths 时的 `read` / `write` / `exec`（`allow` / `ask` / `deny`）。 |
| `workspace` | object | Agent workspace **内**三轴；配置里不写死路径。 |
| `paths` | array | 额外路径规则：`path`、`match`（`prefix` 缺省 / `glob`）、以及该路径三轴。 |


`permission_mode` 映射：`normal` 下 LOW/MEDIUM→allow、HIGH/CRITICAL→ask；`strict` 下 LOW→allow、MEDIUM/HIGH→ask、CRITICAL→deny。未知 severity 按 HIGH。

**Manager 触发**：安全护栏模板变更推送（`push_template_to_gateway`，kind=`permissions_templates`）/ 全量 bootstrap。

**Gateway 推送**：`POST/PATCH/DELETE {gateway_host}/api/v1/permissions-templates[/{id}]`

## 10. MCP 模板（`mcp_template` / `mcp-templates`）

需管理员。创建时服务端生成 `template_id`。

> **MCP**（Model Context Protocol）= 给 Agent 外挂「工具服务器」的协议。Manager 把 MCP 服务写成模板；Agent 的 `template_ref.mcp` 引用后，AgentServer 会用它们整表替换本地 `config.yaml` 的 `mcp.servers`（禁用仅写在本地 yaml 里的 MCP）。

说明：

- Manager 侧校验允许 `stdio` / `sse` / `http` / `streamable-http` / `streamable_http`；下发 Gateway 时企业侧通常**只接受远程 MCP**（`sse` / `streamable-http`）。
- 入参 `transport` 可写别名 `http`、`streamable_http`，推送/存盘时常归一为 SDK 认识的 `streamable-http`。
- 启用开关只认**模板行**的 `enabled`；`mcp_entry` 内的 `enabled` 会被丢弃。



### 10.0 表结构（`mcp_template`）


| 字段名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `id` | INTEGER 自增 PK | 是 | 数据库主键。 |
| `template_id` | VARCHAR(100) UNIQUE | 是 | 对外稳定标识；策略 / Agent `template_ref.mcp` 引用本字段。 |
| `template_name` | VARCHAR(128) | 是 | 模板名称。 |
| `description` | VARCHAR(512) | 否 | 用途说明。 |
| `mcp_entry` | JSON | 是 | 单条 MCP 服务描述（见下）。 |
| `enabled` | BOOLEAN DEFAULT true | 是 | 是否启用（唯一开关）。 |
| `data` | JSON | 否 | 扩展字段。 |
| `created_at` | DATETIME | 是 | 创建时间。 |
| `updated_at` | DATETIME | 是 | 更新时间。 |


`mcp_entry` **字段**（对象）：


| 字段名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `name` | string | 是 | MCP 服务名（写入 `mcp.servers[].name`）。 |
| `transport` | string | 是 | `stdio` / `sse` / `http` / `streamable-http` / `streamable_http`。 |
| `url` | string | 条件 | 远程传输必填。 |
| `command` | string | 条件 | `stdio` 必填。 |
| `headers` | object | 否 | HTTP 头，如 `{"Authorization":"Bearer …"}`。 |
| `timeout_s` | number | 否 | 超时秒数等客户端参数。 |
| 其他 | — | 否 | 透传字段保留；`enabled` 会被剥离。 |


**Manager 触发**：Agent `template_ref.mcp` 引用 / 全量 bootstrap / MCP 模板变更推送（`push_template_to_gateway`）。

**Gateway 推送**：`POST/PATCH/DELETE {gateway_host}/api/v1/mcp-templates[/{id}]`

## 12. 服务配置模板（`service_config_template` / `service-config-templates`）

需管理员。创建时服务端生成 `template_id`。

面向 Runtime / Pod 调度（namespace、容器绑定、并发、TTL 等），**主要下发 Runtime**（`push_template_to_runtime`），**不走** Gateway Config Receiver 的模板 CRUD。

### 14.2 更新 A2A 发现设置

- **请求参数**（Body）：三字段均**必填**


| 字段名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `allow_http` | bool | 是 | 是否允许 http |
| `allow_private_network` | bool | 是 | 是否允许私网；开启后可能扩大 SSRF/内网探测面，生产默认保持 `false` |

- **返回参数**：`data` 为更新后设置
- **副作用**：保存后禁用不合规 outbound 模板，并将网络策略同步到已引用 Gateway；同步失败返回 `502`
- **说明**：示例与表结构默认一致，三开关均为 `false`；仅在受控内网调试时再开 `allow_private_network`
- **请求示例**：

```json
{
  "allow_http": false,
  "allow_private_network": false,
  "allow_public_http": false
}
```

- **返回示例**：

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "allow_http": false,
    "allow_private_network": false,
    "allow_public_http": false
  }
}
```
