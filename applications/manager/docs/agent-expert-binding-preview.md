# Agent 模板专家绑定：前端预览与接口边界

## 用户路径

1. 资源中心 → 专家与专家包：查看资源目录、区分单个专家与专家包（专家团）。当前 Hub 目录通过已有集群读取，离线可主动选择“界面演示（仅预览）”。
2. 工作台 → Agent模板管理 → 新建/编辑：在可选专家能力区多选资源。打开资源中心使用新标签页，原模板表单保留。资源可跨来源查看；目录来源不决定模板的生效范围。
3. 已有模板可单独“保存绑定预览”，不调用模板更新或集群授权接口。新建模板成功后将预览关联到返回的模板 ID；主保存仍保存真实模型等模板配置。
4. 模板详情展示已保存的专家预览。集群新增/编辑 Agent 绑定选择该模板后，展示同一份预览及尚未下发提示，不在集群页重复配置专家。

预览按当前账号、模板 ID 隔离保存在 localStorage。显式取消未保存编辑仍走原有确认。其他浏览器、导入导出和运行时暂不包含这些预览；不会把它们误算成已生效的资源。

## 过渡功能

上游 5c5b09d4 提供的是集群级专家包白名单，资源页的“集群发布（现有功能）”保留这个真实能力。专家资源目录与模板预览不会自动修改白名单。旧集群专家页面地址重定向到资源中心，保留集群和返回路径。

## 后端接入需要确认

- 稳定的全局专家/专家包目录 ID、版本与可用状态；现有目录经 Gateway 获取，需明确跨集群资源一致性。
- Agent 模板的专家引用字段及新增、更新、读取、导入导出契约；不能直接假设现有 `template_ref` 支持新槽位。
- 模板绑定集群时如何与现有专家包白名单、用户/组织范围结合，以及版本失效、取消引用的行为。
- 运行时实际加载和权限校验；接入后由服务端保存记录替换本地预览存储，并显式迁移/确认旧预览。

当前前端不调用不存在的接口，不把演示选择写进真实配置，也不声明专家已部署或可对话。

## 验证

- 前端生产构建通过，87 项前端测试通过；Manager 离线模式、Keycloak 注册及专家目录后端定向测试共 48 项通过。
- 浏览器验证：资源中心入口、旧专家页重定向与返回、真实集群选择刷新恢复、演示目录与现有发布分离。
- 在“[本地演示] 客服助手”选择 1 个专家和 1 个专家包，仅保存浏览器预览；关闭、刷新后详情与绑定集群页均恢复选择。该模板服务器更新时间保持原样，未提交集群授权。
- 真实 Hub、模板专家绑定服务端持久化与运行时执行未验证；后两项尚未实现。
