# Agent 模板统一管理与联动

## 对象与入口

Agent 模板和 Agent 定义是同一种全局资源，对应 `AgentTemplateApi` 和后端 `/v1/agent-templates/`。统一入口为「工作台 → Agent模板管理」，路由为 `/manager/agent-templates`。旧 `/manager/agents` 及其详情、绑定地址保留重定向，查询条件随地址一起保留。

集群中的 Agent 资源是另一个对象：它引用模板，保存集群内的名称、使用条件、启停状态和有效期，对应 `InstanceAgentResourceApi`。绑定模板不会复制出另一份全局模板，也不会自动完成集群准入或运行规格配置。

## 页面与操作

| 页面/区域 | 用户任务 | 联动结果 |
| --- | --- | --- |
| 模板列表 | 搜索、按状态筛选、排序、分页 | 条件保存在 URL；查看详情后可以回到原筛选结果 |
| 新建/编辑模板 | 填写名称和默认模型，可选配置技能、工具与其他资源 | 保存全局模板；新建后提供绑定集群和创建集群的下一步 |
| 模板名称 | 检查能力组合 | 直接打开模板详情，不再经过重复预览页 |
| 模板详情 | 查看引用资源和各集群的绑定 | 从引用资源进入对应目录，从绑定进入对应集群配置 |
| 绑定集群 | 选集群、填写集群内名称、设置使用条件、确认保存 | 创建集群 Agent 资源；保存后进入该集群检查准入、运行资源和状态 |
| 更多操作 | 导出、启停、删除 | 保留原有功能；启停和删除先说明影响并确认 |
| 集群 → 管理/新建模板 | 补齐当前集群需要的模板 | 保留集群上下文；选择或创建后回到原集群并预选模板，仍由用户确认绑定 |
| 资源 → 引用模板 | 找到使用该资源的 Agent | 以资源类型和 ID 精确筛选模板，先读取全部匹配数据再分页 |

## 信息层级

列表只展示模板名称与用途、能力摘要、模板状态、更新时间和常用操作。标签归于名称下；技术 ID、完整引用和绑定信息放入详情。新建和导入是页面级操作；编辑、绑定是行内常用操作；导出、启停和删除归入更多操作。

模板状态只表示模板是否启用，不表示已经部署、资源可用或能对话。页面底部统一解释模板与集群的关系，不使用启用状态作为就绪指标。

## 后端影响

- 模板新建只登记全局目录。
- 模板修改会向引用它的 Gateway 更新模板，成功后写入 Manager 数据库。
- 模板删除会清除引用它的集群 Agent 资源，再删除模板本身；确认框必须明确这一影响。
- 绑定保存使用 `ref_template_id` 关联已有模板；空使用条件仅表示集群中已准入的用户，不授予集群准入。
- A2A 出站目标由访问策略引用，再由 Agent 模板引用策略；不能当作 Agent 模板的直接资源引用。

## 验证边界

自动化检查覆盖旧路由映射、资源引用精确匹配、跨页筛选以及分页错误传播。浏览器检查使用本地 Manager 与身份服务；实际 Gateway 配置下发、Runtime 执行和对话需要运行中的集群联调，不能以模板保存成功替代验证。
