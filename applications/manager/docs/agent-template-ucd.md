# Agent 模板统一管理

## 概念与入口

Agent 模板与 Agent 定义是同一个对象，统一入口为「工作台 → Agent模板管理」，规范地址 `/manager/agent-templates`。不创建新的业务对象或迁移数据，继续使用 `/api/v1/agent-templates/` 接口。原 `/manager/agents` 及其详情、绑定地址通过 replace 重定向，并保留查询条件。

模板负责组合模型、技能、MCP、安全策略等能力，`instance_agent_resource` 负责在具体集群引用模板并限定已准入身份的使用范围。同一模板可以绑定多个集群；模板启用、绑定已保存、网关下发成功、实际可对话是不同状态。

## 页面与操作

| 位置 | 操作 | 结果与上下文 |
| --- | --- | --- |
| 模板列表 | 搜索、状态、排序、分页 | 条件进入 URL；从详情返回可恢复 |
| 模板名称 | 查看详情 | 显示资源名称/状态、集群绑定与使用范围，无摘要抽屉二次跳转 |
| 列表编辑 | 编辑能力组合 | 复用原模板 API；保留已有配置；支持清空描述 |
| 新建模板 | 名称、默认模型 | 默认展示必要字段；其他能力和自定义 JSON 可展开 |
| 表单资源链接 | 补建模型或工具 | 新标签打开资源目录，原表单保留；刷新选项后继续 |
| 保存新模板 | 下一步 | 绑定已有集群，或进入携带模板的新建集群向导 |
| 集群内去新建模板 | 保存并返回 | 按用户与集群暂存绑定名称、描述、使用范围和有效期；返回时携带 `template` 并预选，不覆盖已填名称 |
| 模板详情中的集群绑定 | 管理绑定 | 以 `focusTemplate` 精确筛选全部分页中的关联绑定，不触发新增表单 |
| 集群绑定中的模板名称 | 查看模板 | 新标签打开模板详情，保留原绑定列表与编辑状态 |
| 列表绑定集群 | 配置绑定 | 可选择集群、填写集群中的名称、授权条件，再检查保存 |
| 更多操作 | 导出、启停、删除 | 显示绑定影响；启停和删除确认后提交；失败保留反馈 |
| 导入 | 原工作簿导入 | 保留原依赖预检和导入流程，成功刷新列表 |
| 资源引用数 | 查看关联模板 | 使用 `refType/refId/refName` 精确筛选，跨全部服务端分页 |

## 依赖与反馈

- 集群准入决定谁能进入集群；Agent 绑定条件只在已准入身份中进一步筛选。空条件不自动授予准入。
- 运行资源和模板绑定分别配置；绑定成功后继续在集群工作台检查准入、运行资源和组件状态。
- 新建集群仍使用真实后端可达性检查。未运行 Gateway/Runtime/User Web 的本地环境不能伪报集群创建或对话成功。
- 模板更新会先向引用它的 Gateway 下发，再更新 Manager。删除模板会清除集群绑定，因此保留影响提示和确认。
- A2A 出站资源通过准入策略间接被模板引用；筛选按白名单/黑名单规则计算，不能当作直接模板 ID 引用。
- 可用资源选择器读取全部分页；失败显示重试，不用空列表掩盖加载错误。
- mock 集群只用于演示，列表、详情和绑定入口均保留演示上下文并阻止真实写入。
- 绑定草稿按用户、模板和指定集群隔离；读取失败不能阻断正常配置。集群到模板的草稿在绑定保存成功或明确关闭时清理。

## 验证边界

执行 TypeScript/Vite 构建与 Node 测试；测试覆盖旧路由、查询保留、跨页资源筛选、模板选项分页、引用链解析和错误传播。浏览器使用本地独立 Manager API 检查模板新建/编辑、资源筛选、详情返回和绑定入口。实际网关下发、Pod 重建及对话需要运行中的集群进一步联调。
